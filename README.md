## 🚀 Featured Project

### 🔍 GenAI Q&A Assistant (RAG)
A store Q&A assistant that answers questions **only from your own documents** and says "I don't know" when the answer isn't there.

- **Stack:** Node.js, Express, OpenAI API, PostgreSQL + pgvector, LangChain.js, React
- **How it works:** chunk documents, embed with OpenAI, store vectors in pgvector, retrieve by cosine similarity, and answer with sources
- **Also includes:** tool calling with Zod-validated arguments, a similarity cutoff to reduce made-up answers, and a plain-SDK and a LangChain version of the same pipeline
